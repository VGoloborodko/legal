# Button

Компонент `Button` — это универсальная кнопка для действий и навигации с единым визуальным стилем.

Он поддерживает:

- обычную кнопку через `<button>`;
- ссылку через `<a>` при передаче `href`;
- варианты `brand` и `dark`;
- размеры `md` и `lg`;
- формы `default` и `round`;
- иконки слева и справа;
- disabled-состояние для кнопок и ссылок.

## Когда использовать

Используйте `Button`, если нужен единый компонент для:

- действий внутри интерфейса, например открытие модалки, отправка формы, запуск обработчика;
- внутренних переходов;
- якорных ссылок;
- внешних ссылок, которые должны выглядеть как кнопка.

## Семантика

У компонента два режима работы.

### Режим кнопки

Если `href` не передан, компонент рендерится как `<button>`.

Используйте этот режим для действий:

- открыть попап;
- отправить форму;
- вызвать `onClick`;
- переключить состояние интерфейса.

Пример:

```tsx
<Button onClick={() => console.log('click')}>
  Оставить заявку
</Button>
```

### Режим ссылки

Если передан `href`, компонент рендерится как `<a>`. [web:909]

Используйте этот режим для навигации:

- перейти на другую страницу;
- перейти к якорю на текущей странице;
- открыть внешний ресурс. [web:909][web:1000]

Пример:

```tsx
<Button href="/services">
  Наши услуги
</Button>
```

## Базовые примеры

### Обычная кнопка

```tsx
<Button>
  Оставить заявку
</Button>
```

### Кнопка с обработчиком

```tsx
<Button onClick={() => console.log('click')}>
  Оставить заявку
</Button>
```

### Кнопка отправки формы

```tsx
<Button type="submit">
  Отправить
</Button>
```

### Внутренняя ссылка

```tsx
<Button href="/services">
  Наши услуги
</Button>
```

### Якорная ссылка

```tsx
<Button href="#contacts">
  К контактам
</Button>
```

Для якорной ссылки на странице должен существовать элемент с таким `id`:

```tsx
<section id="contacts">
  ...
</section>
```

### Внешняя ссылка

```tsx
<Button href="https://example.com" target="_blank">
  Открыть сайт
</Button>
```

Если передан `target="_blank"`, компонент автоматически подставляет безопасный `rel="noopener noreferrer"`, если `rel` не указан явно. [web:909][web:1000]

## Пропсы

### Общие пропсы

#### `variant`
- Тип: `'brand' | 'dark'`
- По умолчанию: `'brand'`
- Описание: визуальный вариант кнопки.

#### `size`
- Тип: `'md' | 'lg'`
- По умолчанию: `'md'`
- Описание: размер кнопки.

#### `shape`
- Тип: `'default' | 'round'`
- По умолчанию: `'default'`
- Описание: форма кнопки.

#### `children`
- Тип: `ReactNode`
- По умолчанию: —
- Описание: текст или содержимое кнопки.

#### `icon`
- Тип: `boolean`
- По умолчанию: `false`
- Описание: включает отображение иконки.

#### `iconPosition`
- Тип: `'left' | 'right'`
- По умолчанию: `'right'`
- Описание: положение иконки относительно текста.

#### `iconName`
- Тип: `IconName`
- По умолчанию: `'arrowUpRight'`
- Описание: имя иконки из набора.

#### `fullWidth`
- Тип: `boolean`
- По умолчанию: `false`
- Описание: растягивает кнопку на всю доступную ширину.

#### `fullWidthMobile`
- Тип: `boolean`
- По умолчанию: `false`
- Описание: растягивает кнопку на всю ширину только на мобильных устройствах.

#### `ariaLabel`
- Тип: `string`
- По умолчанию: —
- Описание: текст для accessibility; обязателен для круглой кнопки без текста. Для элементов без видимого названия `aria-label` задаёт доступное имя. [web:1045]

#### `disabled`
- Тип: `boolean`
- По умолчанию: `false`
- Описание: переводит компонент в неактивное состояние.

#### `className`
- Тип: `string`
- По умолчанию: `''`
- Описание: дополнительный CSS-класс.

### Пропсы режима кнопки

Эти пропсы используются, когда `href` не передан.

#### `type`
- Тип: `'button' | 'submit' | 'reset'`
- По умолчанию: `'button'`
- Описание: тип нативной кнопки.

#### `onClick`
- Тип: `MouseEventHandler<HTMLElement>`
- По умолчанию: —
- Описание: обработчик клика.

Пример:

```tsx
<Button type="submit">
  Отправить
</Button>
```

## Пропсы режима ссылки

Эти пропсы используются, когда передан `href`.

#### `href`
- Тип: `string`
- По умолчанию: —
- Описание: адрес ссылки. При наличии `href` компонент рендерится как `<a>`. [web:909]

#### `target`
- Тип: `'_blank' | '_self' | '_parent' | '_top'`
- По умолчанию: —
- Описание: определяет, где открывать ссылку. [web:1000]

#### `rel`
- Тип: `string`
- По умолчанию: —
- Описание: атрибут `rel` для ссылки.

#### `onClick`
- Тип: `MouseEventHandler<HTMLElement>`
- По умолчанию: —
- Описание: обработчик клика по ссылке.

Пример:

```tsx
<Button href="https://example.com" target="_blank">
  Перейти
</Button>
```

## Круглая кнопка

`shape="round"` используется для компактных круглых кнопок, обычно только с иконкой.

Пример:

```tsx
<Button
  shape="round"
  icon
  ariaLabel="Перейти к следующему блоку"
/>
```

### Правила использования `round`

- не передавать текст в `children`;
- использовать `icon`;
- обязательно указывать `ariaLabel`, потому что у такой кнопки нет видимого текстового названия. [web:1045]

## Disabled-состояние

### Disabled для кнопки

```tsx
<Button disabled>
  Оставить заявку
</Button>
```

Для `<button>` используется нативный атрибут `disabled`, который делает элемент неактивным. [web:604][web:608]

### Disabled для ссылки

```tsx
<Button href="/test" disabled>
  Недоступная ссылка
</Button>
```

У ссылки нет нативного `disabled`, поэтому компонент:

- добавляет `aria-disabled="true"`; [web:1051]
- отключает переход;
- позволяет задать отдельные стили для disabled-ссылки.

`aria-disabled` сообщает assistive technologies, что элемент должен восприниматься как неактивный, но не выключает поведение автоматически, поэтому логика блокировки задаётся отдельно в компоненте. [web:1051]

Пример SCSS:

```scss
.button {
  &:disabled,
  &[aria-disabled='true'] {
    opacity: 0.5;
    cursor: not-allowed;
    pointer-events: none;
    box-shadow: none;
    transform: none;
  }

  &:not(:disabled):not([aria-disabled='true']):hover {
    // hover-стили только для активного состояния
  }
}
```

Псевдокласс `:disabled` работает только для элементов, которые реально поддерживают disabled-состояние, поэтому для ссылки нужен отдельный селектор по атрибуту. [web:1013][web:1051]

## TypeScript-типизация

Компонент использует union props, чтобы разделить два режима:

- кнопка;
- ссылка.

Это позволяет отлавливать невалидные комбинации пропсов на этапе компиляции. Union-типизация и narrowing через проверку свойства — стандартный способ описывать такие варианты в TypeScript. [web:958][web:1043][web:1049]

### Корректные примеры

```tsx
<Button onClick={() => console.log('click')}>
  Открыть
</Button>
```

```tsx
<Button type="submit">
  Отправить
</Button>
```

```tsx
<Button href="#contacts">
  К контактам
</Button>
```

```tsx
<Button href="https://example.com" target="_blank">
  Внешняя ссылка
</Button>
```

### Некорректные примеры

```tsx
<Button href="/test" type="submit">
  Ошибка
</Button>
```

```tsx
<Button target="_blank">
  Ошибка
</Button>
```

В таких примерах смешиваются пропсы режима кнопки и режима ссылки.

## Рекомендации

- Используйте `type="button"` для обычных действий внутри формы, если кнопка не должна отправлять форму.
- Используйте `type="submit"` только для отправки формы.
- Не используйте `round` с текстом.
- Для кнопки без видимого текста всегда задавайте `ariaLabel`. [web:1045]
- Для якорных ссылок проверяйте, что целевой `id` существует.
- Для внешних ссылок используйте `target="_blank"` только когда это действительно нужно.

## Частые ошибки

### Передан `href`, но ожидается поведение кнопки

Если передан `href`, компонент работает как ссылка. Для действия без навигации `href` передавать не нужно. [web:909]

### У круглой кнопки нет `ariaLabel`

Кнопка без текстового содержимого должна иметь доступное имя. Для этого используется `ariaLabel`. [web:1045]

### Disabled-ссылка выглядит как обычная

Для ссылки disabled-стиль нужно описывать отдельно через `[aria-disabled='true']`, потому что `:disabled` на `<a>` не работает. [web:1013][web:1051]

### Якорная ссылка не работает

Проверь, что на странице есть элемент с нужным `id`.

```tsx
<section id="contacts">
  ...
</section>
```

## Итог

`Button` — это единый компонент для действия и навигации:

- без `href` он работает как кнопка;
- с `href` он работает как ссылка;
- круглая версия используется для иконок;
- disabled для ссылки требует и логики, и отдельного CSS;
- union-типизация помогает не смешивать режимы использования. [web:909][web:1051][web:958]
