# Modal

Универсальный React-компонент модального окна.

Компонент используется как оболочка для любого контента, который должен открываться поверх страницы через portal.  
Открытие модалки управляется по имени через общее состояние `activeModal`.

## Возможности

- Открытие по уникальному имени модалки
- Закрытие по клику на overlay
- Закрытие по кнопке-крестику
- Закрытие по клавише `Escape`
- Рендер через `createPortal` в `document.body`
- Затемнение и blur заднего фона
- Внутренний скролл модального окна
- Скрытый scrollbar у модального окна
- Блокировка скролла страницы на планшете и мобиле при открытой модалке
- Восстановление позиции страницы после закрытия на планшете и мобиле

## Интерфейс компонента

```ts
type ModalProps = {
  name: string;
  activeModal: string | null;
  onClose: () => void;
  children: React.ReactNode;
  className?: string;
};
```

## Свойства компонента

### `name`

Уникальный идентификатор модалки.

Тип:

```ts
string;
```

Используется для сравнения с `activeModal`.  
Если `activeModal === name`, текущая модалка открывается.

Пример:

```tsx
<Modal name="service-modal" ... />
```

### `activeModal`

Текущее активное окно на странице.

Тип:

```ts
string | null;
```

Обычно хранится в `useState` на уровне страницы или родительского компонента.

Значения:

- `null` — ни одна модалка не открыта
- `'service-modal'` — открыта модалка с именем `service-modal`
- `'policy-modal'` — открыта другая модалка

Пример:

```tsx
const [activeModal, setActiveModal] = useState<string | null>(null);
```

### `onClose`

Функция закрытия модалки.

Тип:

```ts
() => void
```

Вызывается в трёх случаях:

- при клике по overlay;
- при клике по кнопке закрытия;
- при нажатии клавиши `Escape`.

Обычно выглядит так:

```tsx
const closeModal = () => {
  setActiveModal(null);
};
```

### `children`

Содержимое модального окна.

Тип:

```ts
React.ReactNode;
```

Через `children` внутрь модалки передаётся любая ручная вёрстка:

- секции;
- формы;
- текст;
- изображения;
- карточки;
- сетка проекта;
- кнопки и другой JSX.

Пример:

```tsx
<Modal ...>
  <div>Контент модалки</div>
</Modal>
```

### `className`

Дополнительный CSS-класс для модального окна.

Тип:

```ts
string | undefined;
```

Пробрасывается в контейнер `modal__dialog` и используется для модификации конкретной модалки без изменения базовой логики компонента.

Пример:

```tsx
<Modal name="service-modal" activeModal={activeModal} onClose={closeModal} className={styles.modalWide}>
  ...
</Modal>
```

## Принцип работы

Компонент вычисляет состояние открытия по выражению:

```ts
const isOpen = activeModal === name;
```

Логика:

- если `isOpen === true`, модалка рендерится в `document.body`;
- если `isOpen === false`, компонент возвращает `null`.

Это позволяет использовать несколько модалок на одной странице, но показывать только одну активную.

## Поведение при открытии

Когда модалка открывается:

- добавляется обработчик клавиши `Escape`;
- на планшете и мобильных устройствах блокируется скролл страницы;
- сохраняется текущая позиция страницы;
- модалка рендерится через portal поверх основного контента.

Когда модалка закрывается:

- обработчик `Escape` удаляется;
- стили блокировки скролла у `body` очищаются;
- страница возвращается в прежнюю позицию скролла.

## Доступность

Контейнер модального окна содержит:

```tsx
role="dialog"
aria-modal="true"
```

### `role="dialog"`

Сообщает вспомогательным технологиям, что элемент является диалоговым окном, а не обычным контейнером. [web:1352]

### `aria-modal="true"`

Сообщает, что окно является модальным и при его открытии взаимодействие должно происходить внутри него. [web:1343][web:1337]

## Базовое использование

```tsx
'use client';

import { useState } from 'react';
import Modal from '@/components/ui/modal/Modal';

export default function ExamplePage() {
  const [activeModal, setActiveModal] = useState<string | null>(null);

  const openModal = (name: string) => setActiveModal(name);
  const closeModal = () => setActiveModal(null);

  return (
    <>
      <button onClick={() => openModal('service-modal')}>Открыть модалку</button>

      <Modal name="service-modal" activeModal={activeModal} onClose={closeModal}>
        <div>Здесь любая ручная вёрстка модалки</div>
      </Modal>
    </>
  );
}
```

## Несколько модалок на странице

```tsx
<>
  <button onClick={() => openModal('first-modal')}>Первая</button>
  <button onClick={() => openModal('second-modal')}>Вторая</button>

  <Modal name="first-modal" activeModal={activeModal} onClose={closeModal}>
    <div>Контент первой модалки</div>
  </Modal>

  <Modal name="second-modal" activeModal={activeModal} onClose={closeModal}>
    <div>Контент второй модалки</div>
  </Modal>
</>
```

## Где писать содержимое модалки

`Modal` — это только оболочка.

Содержимое модалки рекомендуется писать там, где оно реально используется:

- в `page.tsx`;
- в компоненте секции;
- в локальном компоненте страницы.

То есть:

- `Modal.tsx` — логика открытия, закрытия и portal;
- `Modal.module.scss` — стили оболочки;
- содержимое внутри `children` — локальная разметка страницы.

## Структура модалки

Текущая структура компонента включает:

- `.modal` — корневой overlay-слой;
- `.modal::before` — затемнение и blur фона;
- `.modal__viewport` — контейнер позиционирования окна;
- `.modal__dialog` — модальное окно со скроллом;
- `.modal__wrapper` — внутренний визуальный контейнер;
- `.modal__close` — кнопка закрытия.

## Особенности текущей реализации

- модалка рендерится только в открытом состоянии;
- overlay занимает весь экран;
- клик по корневому слою закрывает окно;
- клик внутри `modal__dialog` не закрывает окно из-за `stopPropagation()`;
- на `<= 1024px` блокируется скролл страницы;
- после закрытия восстанавливается предыдущая позиция страницы;
- scrollbar у диалога скрыт, но сам скролл работает;
- окно поддерживает ограничение по высоте через `max-height`.

## Правило именования

Для каждой модалки на одной странице нужно использовать уникальный `name`.

Примеры:

- `service-modal`
- `review-modal`
- `policy-modal`
- `contacts-modal`

Не следует использовать одинаковые имена для разных модалок в пределах одной страницы.

## Рекомендуемый паттерн

Разделение ответственности:

- `Modal.tsx` — логика и управление состоянием отображения;
- `Modal.module.scss` — стили оболочки модалки;
- страница/секция — конкретный JSX-контент внутри `children`;
- локальные стили страницы/секции — оформление содержимого модалки.
